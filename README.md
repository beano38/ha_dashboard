## Helpers

refering to the vars/room_vars.yml file, this assumes that you need to create a Home Assistant Group Helper:
* Settings -> Devices & services -> Helpers -> Create Helper -> Group
* create a group for switches named the plug_variable_switches, as an example for Office Room the group name would be office_switches
* repeat for lights and mediaplayers
